The first command opens every LÖVE scene in sequence and records an automated screenshot pass. It requires LÖVE 11.5 and Xvfb if no display is available. The GitHub Actions job runs the same pass and uploads the `voiddesk-love-visual-captures` artifact (screenshots, metadata, manifest and logs) for 30 days. Capture mode supplies synthetic system/network values so real host identifiers are not included. The report inventories images and fonts, verifies active LÖVE NEXUS planet images and records screenshot coverage for both engines. Captures are not committed automatically. See [Visual capture workflow](visual/README.md).
