# ❓ FAQ

Quick answers to common questions. Each topic has its own page when it needs a full procedure.

## What is Void Desk?
A controller-first application environment for muOS, with desktop sessions, diagnostics, system tools and network utilities.
- [Read the overview](What-is-Void-Desk)

## How do I install it?
Download the published .muxapp release asset and install it through the muOS Archive Manager.
- [Full installation steps](Installation-muOS-Andromeda)

## What should I do after the first launch?
Check controls, prepare a desktop session, try the live menu and explore THE FORGE.
- [First steps](First-steps)

## Is there a PC version?
Yes. It is mainly intended for development and UI/workflow testing on Linux, not as a replacement for the handheld build.
- [Desktop PC testing](Desktop-PC-testing)

## Which frontend should I use?
Pygame is the reference handheld frontend. LÖVE is experimental and is not feature-equivalent yet.
- [Frontend comparison](Frontends)

## Something does not work. Where do I start?
Record the device, firmware, app version, frontend and exact symptom before changing files or reinstalling.
- [Troubleshooting](Troubleshooting)
