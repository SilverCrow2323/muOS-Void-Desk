# 🚀 First steps

A short route from first launch to a working desktop session. Start with the basics; optional tools can be explored later.

## 1. Start Void Desk
- Open Void Desk from the muOS Applications menu.
- Wait for the main NEXUS screen.
- Check that the detected device and input profile are correct.

## 2. Learn the controls
- Use the D-pad or left stick to move focus.
- Use the on-screen footer to identify the current confirm and back actions.
- Use shoulder buttons only where the current screen shows tab navigation.
- Open the quick panel when the active screen provides it.

> [!IMPORTANT]
> Physical button mappings vary by device, firmware and controller GUID. Follow the icons shown in the UI, not a generic button map from another handheld.

## 3. Prepare a desktop session
- Open **START SESSION**.
- Check available storage before downloading a desktop environment.
- Choose the desktop environment you want to test.
- Download or bootstrap the selected environment.
- Start the session and wait for the graphical desktop.

## 4. Use the live menu
- Open the live menu from the active session controls.
- Use it to reach the available session actions.
- Return to the handheld interface using the displayed exit action.

## 5. Open THE FORGE
- Open **THE FORGE** from NEXUS.
- Review available packages and components.
- Check the operation summary before confirming a change.
- Keep the device powered while an install or update is running.

## Optional next steps
- Configure network services in UPLINK.
- Inspect device health in WORKSHOP.
- Browse installed muOS applications.
- Review [Troubleshooting](Troubleshooting) if a session does not start.

> [!NOTE]
> Desktop availability depends on the installed image, free storage, device model and current implementation.
