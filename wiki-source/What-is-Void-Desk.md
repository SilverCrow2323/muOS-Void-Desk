# 🪐 What is Void Desk?

Void Desk is a controller-first environment that runs as an application inside muOS. It brings desktop sessions, system tools, network services and diagnostics together without replacing the host firmware.

## What it does
- 🖥️ **Desktop environments** — launch supported XFCE, LXDE and IceWM sessions.
- 🧭 **Central hub** — reach diagnostics, utilities and system tools from one interface.
- 🌐 **Network tools** — inspect supported services such as Tailscale, Syncthing and HTTP file sharing.
- 🧰 **System maintenance** — inspect device state, logs, storage and installed components.
- 🎮 **Controller-first UI** — navigate the handheld interface with semantic controls.
- 🧪 **PC testing mode** — test UI and workflows on Linux without a handheld.

> [!IMPORTANT]
> Void Desk is an application layer, not replacement firmware. muOS remains responsible for boot, recovery and the native system environment.

## What it is not
- ❌ Not a new muOS distribution.
- ❌ Not a guarantee that every service is installed or enabled.
- ❌ Not a replacement for physical-device testing.
- ❌ Not a claim that Pygame and LÖVE currently have feature parity.
