# VoidDesk — project wiki

**VoidDesk NEXUS** is a controller-first handheld interface for MustardOS / muOS on compatible Allwinner H700 devices. This wiki is the long-form manual; the repository README remains the quick overview.

> **Engine status:** Pygame is the recommended frontend. The LÖVE frontend is experimental, incomplete and not yet feature-equivalent. Do not select it for daily use unless you are deliberately testing it.
