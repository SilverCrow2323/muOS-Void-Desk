SYSTEM DOSSIER / 01 — ARCHITECTURE

THE MACHINE BEHIND THE INTERFACE

Integration,
not replacement.

Void Desk lives inside the host firmware's supported application lifecycle. QWASAR adds a coherent interface and a growing set of service contracts without taking ownership of boot or recovery.

Trust boundary — a child process can improve responsiveness and crash containment, but process separation alone is not a security sandbox. Executable third-party modules need a separately reviewed permission and isolation model.

03 / INPUT RESOLUTION

One button map
is never universal.

Controller mappings can vary by firmware release, hardware model and SDL controller GUID. A safe resolver must retain that context and expose uncertainty.

01Detect with provenanceEvery field has a source and confidence. Unknown values remain unknown.
02Resolve safelyUnknown firmware uses a generic baseline and calibration, never an invented certified profile.
03Translate semanticallyPhysical inputs become actions such as CONFIRM, BACK, START and QUICK_PANEL.
04Preserve recoveryChanging or invalidating a profile must not trap the user outside native firmware navigation.
