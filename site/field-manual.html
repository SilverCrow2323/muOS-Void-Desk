01 / INSTALLATION

Install from a
published package.

Do not install from the repository source ZIP. The release asset is the packaged application intended for the muOS archive installation flow.

HANDHELD INSTALL / MUOSCHECKLIST Q—01
  1. 01
    Open the official releases

    Choose the published .muxapp asset from the repository Releases page.

    Browse GitHub Releases ↗
  2. 02
    Copy the package to the archive path

    Place the downloaded package in SD1/ARCHIVE/.

  3. 03
    Install with the native archive manager

    On the handheld, open Applications → Archive Manager and install the package.

  4. 04
    Launch from Applications

    Keep the installed application directory and launcher names intact. Existing installs use Void-Desk/ and mux_launch.sh.

04 / FIRMWARE MATRIX

Compatibility is
earned, not assumed.

Firmware family is only one part of controller resolution. Device model and controller GUID must be evaluated together.

Firmware linePositionPolicy
2606.0 AndromedaCURRENT TARGETValidate exact device and controller GUID combinations.
2601.0 JacarandaLEGACYKeep a separate legacy profile family.
2601.1 Funky JacarandaLEGACY VARIANTDo not merge metadata until equivalence is proven.
2612 SupernovaIN DEVELOPMENTPreview only until official release and device tests.
Unknown / otherUNVERIFIEDGeneric safe baseline plus manual calibration.
!

Controller safety — never infer a certified physical mapping from CI or a graphics screenshot. The profile key is firmware release + device model/board + SDL controller GUID.
