🚀 VOID-DESK · ECOSYSTEM i

BaseStation is the operational core of the Void-Desk project for muOS.

Paired with Rt:Server, it expands and optimizes the capabilities of handheld devices, turning them into advanced control stations.

Key features:

  • Embedded terminal (xterm-256color) via WebSocket
  • Service management (SSH, SFTP, FileBrowser, Syncthing, Tailscale)
  • File explorer with drag & drop, copy/paste, rename
  • Framebuffer screenshots with preview and management
  • Real-time system resource monitoring
  • Two-way sync PC ↔ Console for saves, states, screenshots

Project: github.com/SilverCrow2323/muOS-Void-Desk

⌨ COMMAND CENTER i

Embedded terminal: WebSocket connection to ttyd (port 8080).

Quick commands: One-click diagnostic commands.

System control: Power off, reboot, drop cache, sync clock.

Custom commands: Send any command to the terminal.

External terminal: Copy SSH command for your local terminal.

Screenshots: Capture framebuffer via SSH, saved to /mnt/mmc/MUOS/screenshot/.

⟳ TWO-WAY SYNC i

Two-way synchronization PC ↔ Console follows the "newest wins" principle:

  • Files with the most recent modification time are copied
  • No files are ever automatically deleted
  • Perfect for saves, states, and screenshots

Default sync pairs:

  • Saves → /mnt/mmc/MUOS/save/file
  • States → /mnt/mmc/MUOS/save/state
  • Screenshots → /mnt/mmc/MUOS/screenshot

Note: Sync uses SFTP (port 2022) with muos/muos credentials.
